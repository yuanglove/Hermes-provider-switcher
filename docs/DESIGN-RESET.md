# 重置版视觉与交互设计

## 设计定位

CC Switch 仅作为功能参考。本项目采用“配置轨道工作台”方向：用户先选择平台，再在同一工作区完成供应商、路由和资源操作，减少页面跳转；设置与关于信息通过右上角入口进入，不复制参考项目的导航和卡片结构。

## 视觉识别

- 应用图标使用带橙紫光环的黑洞：黑色事件视界代表统一入口，光环代表不同平台和模型围绕入口切换。
- 图标源文件：`assets/hermes-blackhole.svg`。
- Windows/Tauri 图标位于 `src-tauri/icons/`，顶部工作台使用同一图形，避免应用图标与界面品牌不一致。
- 主题保持中文浅色优先，并随系统切换；交互色采用浅色背景，保证悬停状态下文字对比度。

## 工作区布局

- 顶部：品牌标识、当前平台上下文、设置和更新入口。
- 平台导航：供应商、MCP、Skills、提示词、会话、设置，以紧凑的工作区标签呈现，而不是参考项目的相同侧栏。
- 内容区：供应商和资源操作留在当前上下文；表单、导入、同步和备份使用局部面板完成。
- 大型页面懒加载，启动阶段不联网、不扫描外部工具。
